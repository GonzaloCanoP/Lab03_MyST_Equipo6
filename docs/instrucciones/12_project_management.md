# 12 — Gestión del proyecto

**Dueño:** Juan Manuel Espinosa (JME) (charter, sprints 01–02); cierre de sprint y post-mortem ambos · **Carpeta:** `project_management/`

## Loop semanal

```
CADA SEMANA:
  1. Al inicio: crear sprint_NN.md con objetivo (2–3 oraciones) y tareas con responsable.
  2. Durante: actualizar estado de tareas; anotar bloqueos y desviaciones.
  3. Al cierre: revisar hitos del charter, riesgos del registro y balance de commits (git shortlog -sn --no-merges).
```

## Checklist

- [ ] `charter.md` (1 página): alcance (hará / no hará), hitos con fechas, ≥ 5 riesgos con probabilidad/impacto/mitigación, roles con referencia a commits esperados.
- [ ] Un `sprint_NN.md` por semana, con objetivo, tareas + estado, bloqueos.
- [x] `postmortem.md` (1–2 páginas) al final: hitos a tiempo/retrasados y por qué, cuellos de botella técnicos y organizacionales, qué cambiaría en producción, riesgos materializados.
