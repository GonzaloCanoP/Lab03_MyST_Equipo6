# Notas de clase

Un archivo por tema, generado a partir de las presentaciones del curso. Son la **fuente de verdad** de notación
y enfoque: el código y el reporte deben usar la misma notación.

| Archivo | Tema | Lo usan |

| `02_pairs_trading_secuencial.md` | Pairs trading como problema de decisión secuencial | 04, 05, 06, 09 |

| `04_johansen_vecm_kalman_multiactivo.md` | Johansen, VECM y arbitraje multi-activo con Kalman | 02, 03, 05 |

Plantilla sugerida para cada nota:

1. **Ideas clave** (5–10 bullets).
2. **Notación** usada en clase (tabla símbolo → significado → nombre de variable en el código).
3. **Ecuaciones** centrales.
4. **Algoritmo / pasos** tal como se vio.
5. **Cómo aplica al Lab03** (qué archivo/función lo implementa).
6. **Decisiones que la clase deja abiertas** → llevarlas a `docs/decisiones.md`.
7. **Preguntas tipo quiz/exposición**.
